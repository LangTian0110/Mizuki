# Git 提交信息

所有提交信息使用中文，格式为：

图标 类型 → 简述

## 图标与类型

🌙 功能 → 新增功能或内容模块
☕ 修复 → 修复缺陷或异常
💤 样式 → 界面样式与视觉调整
📝 文档 → 文章、页面等文档内容更新
🌚 重构 → 代码结构优化
🛏️ 杂项 → 依赖更新、配置修改等

## 示例

🌙 功能 → 文章页添加目录导航组件
☕ 修复 → 修复移动端代码块横向滚动失效
💤 样式 → 统一首页标题字号与间距
📝 文档 → 发布《现代CSS布局完全指南》
🌚 重构 → 拆分首页组件，抽离公共逻辑
🛏️ 杂项 → 升级marked依赖至最新版本
